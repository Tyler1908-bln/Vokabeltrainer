# Spanisch Vokabeltrainer

Ein installierbarer, mobiler Vokabeltrainer für Schüler. Die App fühlt sich auf Handy und Tablet wie eine richtige App an und speichert Daten lokal auf dem Gerät.

## Vorbereitet

- TypeScript + React + Vite
- Installierbare App
- Deutsche Benutzeroberfläche
- Layout für Handy und Tablet
- Karteikarten, Multiple Choice, Schreiben, schwierige Wörter
- Kategorien für eigene Listen
- Lokale Speicherung ohne Login
- Vorbereiteter Bereich für Kamera-Scan

## Starten

1. Node.js installieren: https://nodejs.org/
2. Im Projektordner ausführen:

```powershell
npm install
npm run dev
```

3. Danach die angezeigte Adresse im Browser öffnen.

## Hinweis zum Scan

Der Scan-Bereich ist als erste Version vorbereitet. Im nächsten Schritt kann dort echte Texterkennung für gedruckte Listen eingebaut werden.
